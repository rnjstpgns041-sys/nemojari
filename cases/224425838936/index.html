요청 내용

주방 후드가 돌아가긴 하는데 흡입력이 많이 약해져서, 새 제품으로 바꿔 달라고 하셨어요.

현장 상황

상부장 사이에 달린 기존 후드는 겉보기엔 멀쩡했지만, 요리할 때 냄새와 연기가 잘 안 빠졌어요. 청소로 버티기보다 같은 자리에 새 후드를 다는 쪽으로 정했어요.

이렇게 작업했어요

  1. 기존 후드의 전원과 배기 연결 상태를 먼저 확인했어요
  2. 전원과 배기 연결을 분리하고 주방장이 상하지 않게 기존 후드를 떼어 냈어요
  3. 배기구 주변을 정리한 뒤 새 후드를 한쪽으로 치우치지 않게 자리 잡았어요
  4. 배기와 전원을 연결하고 흔들리지 않도록 단단히 고정했어요
  5. 직접 켜 보면서 흡입력, 소음·진동, 조명까지 점검했어요

결과

새 후드가 기존 주방장 사이에 깔끔하게 들어갔고, 흡입과 조명 모두 정상적으로 쓸 수 있게 됐어요.

알아두면 좋아요

후드는 제품마다 폭·깊이·배기 연결 방식이 다를 수 있으니, 새로 사기 전에 지금 달린 후드 크기와 배기구·전원 위치부터 확인해 두세요.
