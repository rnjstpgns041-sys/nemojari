냉장고 폭이 안 맞을 때 옆 수납장 철거

냉장고장2026.09.13

요청 내용

새로 산 냉장고가 기존 냉장고장보다 커서, 들어갈 수 있게 공간을 넓혀 달라고 하셨어요.

현장 상황

기존 냉장고는 이미 빠진 상태였고, 냉장고 칸 옆에 세로로 긴 수납장이 붙어 있었어요. 새 냉장고는 폭이 더 넓어서 이 수납장을 두고서는 자리가 모자랐어요.

이렇게 작업했어요

  1. 기존 냉장고장 구조와 새 냉장고 크기를 비교했어요
  2. 왼쪽 세로 수납장을 철거해서 냉장고 폭을 넓혔어요
  3. 철거한 수납장 중 쓸 만한 부분으로 냉장고 위 상부장을 다시 만들었어요
  4. 새 상부장이 기존 장과 자연스럽게 이어지도록 전체 마감을 했어요

결과

냉장고장 전체를 새로 짜지 않고도 대형 냉장고 들어갈 자리를 만들었고, 수납공간도 상부장으로 살렸어요. 새 냉장고가 오기 전에 미리 준비를 끝내 둔 현장이에요.

알아두면 좋아요

큰 냉장고를 샀다고 장을 다 새로 짤 필요는 없고, 입고 전에 폭·높이·깊이를 재서 필요한 부분만 고치면 돼요.
