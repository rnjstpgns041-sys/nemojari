물먹어 부푼 싱크대 하부장 부분 수리

주방2026.07.31

요청 내용

싱크대 아래쪽 판이 물을 먹어서 부풀었다며, 상태를 보고 수리해 달라고 하셨어요.

현장 상황

싱크대 주변 하부가 여러 군데 물에 부풀고 뜯어져 있었고, 안쪽 MDF까지 물러진 상태였어요. 통째로 바꾸면 비용 부담이 크고 새 필름은 색이 달라질 수 있어서, 교체 대신 복원 수리로 가기로 했어요.

현장: 충남 아산시

이렇게 작업했어요

  1. 전용 도구로 물먹은 겉면을 긁어 내고 부서지는 부분을 정리했어요
  2. 물러진 부위를 깨끗이 걷어 내 복원 작업 준비를 했어요
  3. 기존 필름 색에 맞춰 퍼티를 채웠어요
  4. 각도와 라인을 다듬고 나뭇결에 맞춰 단차를 잡았어요
  5. 시트지와 조색으로 기존 가구와 같은 색을 맞췄어요

결과

제품을 바꾸지 않고 복원만으로 곰팡이나 냄새 없이 깔끔하게 되살렸고, 고객님도 아주 만족하셨어요.

알아두면 좋아요

물먹은 하부장은 그냥 두면 점점 부풀고 곰팡이까지 생길 수 있어서, 손상이 깊어지기 전에 빨리 고치는 게 비용을 아끼는 길이에요.
