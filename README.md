# 네모자리 홈페이지

`index.html` 한 파일과 `img/` 사진 폴더로 된 정적 홈페이지예요. 이 저장소의 main 브랜치에 올라간 내용이 Netlify에 자동으로 반영돼요.

## 통계

- `/admin/stats/` : 사장님용 방문·문의 통계 (비밀번호 6자리, 검색 제외). 처음 들어가면 비밀번호를 정하는 화면이 나온다.
- 각 페이지 하단 스크립트가 `/api/t` 로 방문·버튼 클릭을 보낸다. 방문자는 기기에 저장한 무작위 번호로만 구분하고, 이름·연락처는 저장하지 않는다.
- 저장은 Netlify Blobs (`netlify/functions/track.mjs`, `stats.mjs`). 비밀번호는 해시로만 저장하고, 5번 틀리면 15분 잠긴다.
